# Getting started

The guide for this package lives on the Tarinoi documentation site, so it stays current
independently of package releases:

**https://tarinoi.app/docs/plugins/unity**

It covers installation, pointing Unity at your Tarinoi project, syncing, generating and
implementing bindings, the runtime events, the trigger components, seen-card history and
the `shown_once` flag, shipping a build, the settings reference, and troubleshooting.

Related reading:

- [What the plugins do and don't do](https://tarinoi.app/docs/plugins/) — scope, intent, and which engine versions are supported
- [Writing your own integration](https://tarinoi.app/docs/plugins/writing_your_own) — the engine-agnostic data contract
- [Adapting a plugin](https://tarinoi.app/docs/plugins/adapting) — forking this package, porting it, and the traps we hit building it

For a runnable starting point, import the **Quickstart** sample from the Package Manager
window.
